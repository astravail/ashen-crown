# Utviklingsplan

## Fase 1: Grunnlag

- [ ] Lag tre klasser først: Ashen Knight, Gravecaller og Pyrewitch (nærkamp, minions og magi)
- [ ] Bygg et felles evnesystem: cooldowns, ressurser, skadetyper og statuseffekter
- [ ] Lag fem til seks evner per klasse og test hvordan de føles i kamp

## Fase 2: Progresjon

- [ ] Evnemodifikatorer (3–5 varianter per evne)
- [ ] Passive evner (3–4 aktive samtidig)
- [ ] Kronefragmenter

## Fase 3: Utvidelse

- [ ] Legg til Dusk Stalker, Ember Monk og Hexbinder
- [ ] Klassesett (utstyrssett som muliggjør bestemte bygg)
- [ ] Balansering: mål skade per sekund og overlevelse i testmiljøer

## Åpne spørsmål

- Hvilken spillmotor? (Godot, Unity, Unreal)
- 2D isometrisk eller 3D?
- Singleplayer først, eller co-op fra start?
- Navnet ble byttet fra «Ashen Crown» til «Pyrewake» i 0.6.0, fordi «Ashen Crown» allerede var tatt på Steam
